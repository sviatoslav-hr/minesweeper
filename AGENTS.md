# Project guidelines

## Dependencies

This project avoids external dependencies where practical. Prefer platform APIs and code maintained within the project.

Do not add or install a dependency without explicit user approval. Before asking for approval, explain why the dependency is necessary and why the existing project or platform cannot reasonably provide the needed functionality.

## UI design

Follow `docs/ui-guidelines.md`. Topbar blocks, including readouts, follow the numbered-cell background colors in left-to-right order.

## Development servers

Stop any Vite development or preview server you started when you finish the task, unless the user asks you to leave it running. Do not stop servers that were already running before your task.
